# CarPaintFinder review gate

## Completed in repository
- Next.js homepage and responsive make/model/year/code form
- PostgreSQL verified-record query and HTTP API
- Schema with manufacturer, model, paint-code, model-year and source tables
- Source validation and pre-launch content
- robots.txt disallows crawling until launch review

## Must pass before public launch
- [ ] GitHub Actions typecheck and production build pass
- [ ] PostgreSQL provisioned and migration applied
- [ ] API smoke tests with manually verified sample records
- [ ] Source licenses and redistribution rights reviewed
- [ ] OEM paint-code and model-year applicability independently verified
- [ ] Original label-location illustrations produced
- [ ] Operator identity and contact details added to legal pages
- [ ] Mobile, accessibility and SEO manual QA
- [ ] Domain DNS and HTTPS configured
- [ ] Enable indexing only after substantive verified content is published

## Critical data rule
Never imply that a VIN itself contains the paint code. No manufacturer paint-color records are presented as verified until source documentation has been inspected.
